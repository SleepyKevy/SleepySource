Now Playing is not updatingConfirm music is playing, then check Media-session source and Include/Exclude filters. Make sure SleepySource sees the track before troubleshooting OBS.
Kick is connected but chat is missingOpen Connections and confirm Account, Kick Events, and Realtime are healthy. Use Sync Kick Events to rebuild the managed subscriptions if delivery needs attention, then check System Health.
Countdown will not startCheck Timer Setup & Presets → Start behavior. Manual mode needs Start; Browser Source mode needs the /countdown page to load.
OBS Browser Source is blankKeep SleepySource running, verify the local URL, match the canvas dimensions, and refresh the Browser Source.
Designer does not openInstall Microsoft Edge WebView2 Runtime, fully exit SleepySource from the tray, then reopen it.

OBS Setup Guide
1. Add SleepySource to OBS

In OBS, add a Browser Source and use http://127.0.0.1:17891/overlay.

2. Match the canvas

Set the OBS Browser Source width and height to the values in Overlay Canvas. Default is 900 × 180.

3. Smooth playback

Enable Use custom frame rate in the OBS Browser Source and use 60 FPS, or match your OBS video FPS.

4. Build your design

Drag, resize, snap, use keyboard nudging, presets, and save the finished configuration as an overlay profile.
