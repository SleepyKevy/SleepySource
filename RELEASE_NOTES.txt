SLEEPYSOURCE™ 1.1 — RELEASE NOTES
=================================
Made by SleepyKev • 2026

SleepySource 1.1 is the current pure C#/.NET release line.

1.1 RELEASE UPDATE
------------------
- Updated SleepySource product/version branding from 1.0 to 1.1 across the desktop host, local API state, web UI fallbacks, executable metadata, user-agent strings and update-version comparison.
- Preserved the existing C#/.NET architecture, OBS routes, settings/profile formats and portable SleepySource_Data layout.
- Retained the latest sidebar, Tools and accordion-bar cleanup already present in the release candidate.
- Kept the existing update-check behavior unchanged.

-------------------------
- Replaced the transitional Go compatibility backend with in-process C#/.NET 8 services.
- Removed the SleepySource.Engine.exe runtime dependency.
- Preserved the existing WebView2 interface and OBS Browser Source workflow.
- Preserved the local service address at 127.0.0.1:17891.
- Preserved the SleepySource_Data portable data location and existing route structure.

STARTUP EXPERIENCE
------------------
- Added a fully branded SleepySource WebView2 splash/loading experience using the high-resolution raccoon mark.
- Added smooth staged progress, subtle ambient particles, cyan/blue lighting, a restrained logo sheen and a final Ready pulse.
- At 100%, Ready triggers a subtle final logo pulse and smooth fade, then the C# host opens the dashboard only after its backend-ready gate succeeds.
- Refined progress interpolation, status crossfades, ambient timing and the final dashboard hand-off without changing the splash layout.

C# SERVICES
-----------
SleepySource handles the local HTTP/OBS server, settings/state, profiles/backups, Alert Studio, chat, Countdown Pro, Kick integration, stream authentication/settings, Cloudflare relay control, Windows media sessions, health checks and update handling directly in C#.
