SLEEPYSOURCE™ 1.0 — RELEASE NOTES
=================================
Made by SleepyKev • 2026

SleepySource 1.0 is the revamped pure C#/.NET release line.

CORE REVAMP
-----------
- Replaced the temporary Go compatibility backend with in-process C#/.NET services.
- Removed the SleepySource.Engine.exe runtime dependency.
- Preserved the existing WebView2 interface and OBS Browser Source workflow.
- Preserved the local service address at 127.0.0.1:17891.
- Preserved the SleepySource_Data portable data location and existing route structure.

C# SERVICES
-----------
SleepySource now handles the local HTTP/OBS server, settings/state, profiles/backups, Alert Studio, chat, Countdown Pro, Kick integration, stream authentication/settings, Cloudflare relay control, Windows media sessions, health checks and update handling directly in C#.

DESKTOP BEHAVIOR
----------------
- Windows desktop host remains WinForms + WebView2.
- Mouse Back/Forward navigation remains blocked inside SleepySource.
- Minimizing keeps the taskbar button visible while the tray icon remains available.
- Closing with the window X exits SleepySource completely.

VALIDATION
----------
- .NET 8 win-x64 restore/publish: PASS
- Self-contained single-file SleepySource.exe: PASS
- Legacy SleepySource.Engine.exe absent from published output: PASS
- Pure C# Windows runtime/API smoke suite: PASS

Windows x64 only. The application remains unsigned, so Windows SmartScreen may warn on first launch.
