SLEEPYSOURCE™ 1.0 — RELEASE NOTES
=================================
Made by SleepyKev • 2026

SleepySource 1.0 is the revamped pure C#/.NET release line.

CORE REVAMP
-----------
- Replaced the transitional Go compatibility backend with in-process C#/.NET 8 services.
- Removed the SleepySource.Engine.exe runtime dependency.
- Preserved the existing WebView2 interface and OBS Browser Source workflow.
- Preserved the local service address at 127.0.0.1:17891.
- Preserved the SleepySource_Data portable data location and existing route structure.
- Final visible product/version branding is SleepySource 1.0.

C# SERVICES
-----------
SleepySource now handles the local HTTP/OBS server, settings/state, profiles/backups, Alert Studio, chat, Countdown Pro, Kick integration, stream authentication/settings, Cloudflare relay control, Windows media sessions, health checks and update handling directly in C#.

COMPATIBILITY FIXES FOUND DURING MIGRATION
------------------------------------------
- Matched legacy API response wrappers and optional/default fields.
- Fixed alert consumption when an alert has no custom visual or sound media.
- Fixed backup restore when managed media/profile folders are empty or absent.
- Preserved countdown font-upload response behavior.
