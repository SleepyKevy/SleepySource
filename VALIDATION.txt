IMPORTANT RUNTIME LIMITATION OF THIS WORKSPACE
----------------------------------------------
The current Linux workspace does not contain the .NET SDK or a Windows runtime,
so it cannot truthfully perform a fresh win-x64 publish or launch the Windows GUI.
Network access from the build container is also unavailable, so the .NET SDK
cannot be downloaded here.

The supplied Public executable came from the previously working package. This
release line previously changed version/product identity with equal-length binary
string replacements. This endpoint migration additionally retargets the managed
API string metadata inside the supplied single-file bundle while preserving the
outer executable size and bundle manifest layout; its PE/bundle structure is
revalidated here. A true Windows launch/API smoke test should still be run before
publishing the GitHub Release.

The Source package includes BUILD_RELEASE.ps1 and
.github/workflows/csharp-runtime-smoke.yml. Either can perform the real .NET 8
win-x64 publish/runtime smoke test on Windows / GitHub Actions.
