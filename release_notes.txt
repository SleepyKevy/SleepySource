SLEEPYSOURCE™ 1.0.0 — RELEASE NOTES
============================================
Made by SleepyKev • 2026-08-17

RELEASE STATUS
--------------
SleepySource 1.0.0 is the first consolidated release of the current
C#/.NET + WebView2 application line. This file contains the complete
development changelog for the 1.0.0 release line.

1.0.0 RELEASE CONSOLIDATION
------------------------------------
- Standardized active product/version branding to SleepySource 1.0.0.
- Updated executable/project metadata to 1.0.0 / 1.0.0.0 release values.
- Updated desktop window, tray, single-instance identity, update comparison,
 user-agent identity, WebView page titles, splash build label, footer, and
 version fallbacks for the 1.0.0 release line.
- Renamed the source build script to BUILD_RELEASE.ps1 and updated its output
 folder to “SleepySource 1.0.0”.
- Updated the GitHub Windows runtime-smoke workflow title/artifact naming for
 the release.
- Replaced pre-release validation/package wording with release wording.
- Added a condensed detailed README.txt to both Public and Source packages.
- Added this consolidated release_notes.txt to both Public and Source packages.

NAVIGATION / CONNECTIONS UPDATE
-------------------------------
- Moved Connections out of the Tools drop-down.
- Added Connections as a standalone main navigation tab directly below Home.
- Tools now contains the streamer tools only: Now Playing, Chat Overlay,
 Alert Studio, Stream Dashboard, and Countdown Pro.
- Updated active-state logic so opening Connections does not highlight Tools.
- Preserved the existing SleepySource visual style and Connections workspace.

SLEEPYSERVICES ENDPOINT MIGRATION
----------------------------------
- Kept the product version at SleepySource 1.0.0.
- Moved the hosted SleepySource API base from the retired account Workers subdomain to https://sleepysource-api.sleepyservices.workers.dev.
- Updated desktop OAuth start/status, API health, persistent connection, realtime,
  stream proxy, and hosted event calls to use the sleepyservices endpoint.
- Updated the packaged Cloudflare Worker health/webhook URLs and deployment docs
  so a future Worker redeploy does not restore the retired subdomain.
- Preserved the existing Kick redirect path, webhook path, D1 binding, realtime
  Durable Object binding, and SleepySource 1.0.0 product/version identity.
- Release package filename is SleepySource_1.0.0.zip (no “Public” suffix).


KICK EVENT DELIVERY REPAIR
--------------------------
- Kept the product version at SleepySource 1.0.0.
- Changed hosted Kick event sync into a repair-safe rebuild: existing SleepySource-managed
  subscriptions are removed and recreated against the Kick developer app's current webhook URL.
- This repairs stale subscriptions after the legacy Workers subdomain -> sleepyservices webhook migration
  and other cases where Kick reports subscriptions as active but stops delivering events.
- Rebuild is limited to SleepySource's managed required events; unrelated subscriptions are left alone.
- The desktop Sync Kick Events action now reports that subscriptions were refreshed.
- Public ZIP layout now contains one top-level folder named “SleepySource 1.0.0”.


CLOUDFLARE / KICK FINAL CLEANUP
-------------------------------
- Kept the product version at SleepySource 1.0.0.
- Confirmed the new Kick Developer App delivers chat events to the sleepyservices webhook.
- Confirmed Kick chat reaches the hosted Worker, realtime/D1 delivery, and Chat Overlay.
- Declared Workers Logs in wrangler.jsonc so invocation logging and dashboard persistence survive future deployments.
- Removed the final legacy Workers-account hostname text from the packaged source/deployment scripts.
- Preserved the SleepySource 1.0.0 public ZIP layout with one top-level “SleepySource 1.0.0” folder.

HOSTED KICK OAUTH / CONNECTION SYSTEM
-------------------------------------
- Added one hosted Connect with Kick flow shared by Chat Overlay, Alert Studio,
 and Stream Dashboard.
- Removed desktop Client ID / Client Secret entry and the legacy saved Kick
 developer-credential flow.
- Removed the local Kick OAuth callback and separate Stream Controls
 authorization flow.
- Removed Cloudflare Quick Tunnel runtime usage, trycloudflare.com webhook flow,
 and manual webhook registration controls.
- Added SleepySourceApiService for hosted OAuth session polling, persistent
 connection status, managed event subscriptions, realtime WebSocket delivery,
 and D1-backed reliable queue fallback.
- Desktop persistence keeps only the opaque SleepySource connection credential.
- Legacy kick_credentials.json and kick_user_authorization.json are removed
 during migration.
- Added authenticated Worker proxies for stream metadata, category search, and
 title/category updates so Kick user tokens stay server-side.
- Added managed kicks.gifted and channel.reward.redemption.updated events in
 addition to chat, follows, and subscription events.
- Stream Dashboard inherits the shared Kick connection instead of requiring a
 second authorization flow.
- System Health reports hosted SleepySource API, Kick authentication, managed
 event subscriptions, realtime delivery, and D1 fallback status.

OAUTH COMPLETION HOTFIX
-----------------------
- Fixed the desktop OAuth-pending JSON contract where OAuthPending could be
 serialized as o_auth_pending while the UI expected oauth_pending.
- Added an explicit oauth_pending JSON property name in the C# hosted Kick state.
- Added UI compatibility for both oauth_pending and o_auth_pending.
- Added status-based polling for authorizing / finishing OAuth states.
- OAuth completion errors are surfaced instead of being silently ignored during
 the polling handoff.

BRANDED HOSTED CONNECT FLOW
---------------------------
- Added a branded SleepySource /connect/kick page hosted by the Cloudflare Worker.
- Connect with Kick opens the SleepySource page first, then continues to Kick.
- Kept desktop compatibility by returning the branded page in authorize_url.
- Branded OAuth success/error result pages with the SleepySource visual style.
- Hardened callback failure handling so a post-approval Worker error is stored
 as a terminal OAuth failure instead of leaving the desktop stuck processing.
- Standardized the packaged Cloudflare source filename as worker.js.

CORE C# / .NET APPLICATION FOUNDATION
-------------------------------------
- Replaced the transitional Go compatibility backend with in-process C#/.NET 8
 services for the current application line.
- Removed the SleepySource.Engine.exe runtime dependency.
- Preserved the existing WebView2 interface and OBS Browser Source workflow.
- Preserved the local service address at 127.0.0.1:17891.
- Preserved the portable SleepySource_Data location and existing route structure.
- C# services handle local HTTP/OBS serving, settings/state, profiles/backups,
 Alert Studio, chat, Countdown Pro, media sessions, hosted Kick connection
 bridging, stream settings, health checks, and update handling.
